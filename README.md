# Runner Game (Conestoga Game Jam Entry)

This project was created during the Conestoga College Indie Game Jam, held in February 2025. Our team developed a simple running game using the Unity game engine.

---

## Project Description

The goal of this game jam entry was to prototype a functional endless runner or racing game focusing on core mechanics and audio integration. We aimed to create an engaging experience with custom sound effects and simple object interactions.

## Key Features

*   **Unity Engine:** The entire game was developed using Unity.
*   **Audio Design:** Custom background music (BGM) and essential racing sound effects were created and integrated into the gameplay.
*   **Object Creation:** We designed and implemented several key assets:
    *   **Runner Objects:** The main racing participants/characters.
    *   **Items:** Collectible in-game items to enhance gameplay (e.g., speed boosts or obstacles).
